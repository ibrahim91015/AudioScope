# AudioScope 0.3.0

- Record all turns red only after its own action and actual audio from every non-hidden source. Gray monitor waveforms become accent-colored during recording, with smoother peak/progress animation and short button/screen transitions.
- Compact Sessions cards open a dedicated full-screen recording with real waveform seeking, all tracks, play/pause, skip, speed, rename and sharing.
- Auto recommendations select multiple audible sources and can add them to an existing recording.
- Persistent custom save folder, finished-file export, optional JSON metadata and local Files/Recent indexing. Private originals survive export failures.
- Ordinary microphone presets request and verify phone input. Connected Bluetooth mic presets require explicit monitoring/recording; settings control headset selection, call-audio routing, sample rate and preview behavior.
- Optional local caller/app/direction naming and editable filenames, using phone call-log/contact access and ongoing VoIP call notifications when available.
- Standard text remains the default. Global format propagation, four editable Sources densities, hidden-route resource release, repair notifications, offline Embedded ADB pairing and call automation remain available.

See docs/VALIDATION.md and docs/REQUIREMENTS-0.3.0.md for checks and device-specific limits. Install over 0.1/0.2; finish recording before updating and reconnect the helper afterward. Physical CMF media routing, Samsung Recent and app-specific caller naming remain phone checks.
