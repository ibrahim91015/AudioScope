# AudioScope 0.5.0 — mic continuity and recording-safe Sources

Opening Sources during an existing mic recording used to start competing previews. The route check also incorrectly treated Android’s telephony input as an external microphone. Extra previews now pause throughout capture/finalization, display an understandable conflict message, and cannot start by tapping a mic preview. Local mic preview cleanup no longer calls the privileged helper’s close operation. Recording rows use the actual recording’s waveform.

**Any Phone Mic** is the default input and idle phone preview. It starts the ordinary MIC preset with a built-in preference, tries other local presets if initialization fails, follows non-Bluetooth mic changes and attempts bounded dead-recorder recovery within the same WAV. Regular Microphone accepts built-in/telephony device routes. Wrong-device PCM is discarded while a short route recovery is attempted. Confirmed Bluetooth input is never accepted by phone sources. Other physical mic previews require an explicit tap and only one owns the input at a time.

Bluetooth settings adds **Record Bluetooth mic now**, **Hold Bluetooth mic until stopped** (default on) and **Show each connected microphone** (default on). Sources adds **Any Bluetooth Mic** plus named connected Bluetooth/USB/wired inputs. Headset capture holds its chosen route, reasserts it when Android changes communication routing, and transfers a preview’s ownership into recording. It does not silently switch to another headset or the phone. Disconnects and rejected routes still produce repair messages. Android Telecom remains authoritative during managed phone calls, and Android may expose only one usable headset mic.

Mono mixing is enabled by default on installation and upgrade. **Normalize track levels in mix** is configurable and defaults on: peak normalization aims for −3 dBFS with approximately 12 dB maximum amplification, then applies weighted mix headroom. This changes the mix only, leaves original tracks untouched, and does not claim perceptual speech loudness equalization. Sessions shows the mix as its default player; the full-screen recording retains all individual tracks and their names.

**Restart capture helper without Wi-Fi** explains ordinary offline recording separately from optional helper restart transport. Its opt-in dialog explains network exposure, authorized debugging keys, powerful shell access, differences from Wireless debugging TLS, trusted-network use, listener shutdown and reboot expiry. Existing helper/debugging functionality is retained.

Validation: clean signed/debug/test builds, 25 unit cases, zero lint errors (26 warnings), three new actual-PCM/navigation emulator regressions and five adjacent device regressions. UI screenshots review Sources, Bluetooth settings, mix settings, session list/detail and the expanded security popup. The specific Samsung mic switching, CMF headset behavior and multiple external devices need physical confirmation; emulator tests do not establish those hardware outcomes. See [validation](VALIDATION.md).

Finish recording before installation and reconnect the capture helper after updating. The same signing key permits an in-place update with existing recordings/preferences retained. The first 0.5 launch enables Mono mix and moves the untouched default Microphone + VoIP selection to Any Phone Mic + VoIP. Custom selections remain unchanged.
