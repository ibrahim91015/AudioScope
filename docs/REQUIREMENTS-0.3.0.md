# Requirement audit — AudioScope 0.3.0

The original research markdowns are design input. This audit covers the user's requests, including the later Bluetooth, multi-source recommendations, full-screen Sessions and caller naming. CallVault's capture, pairing, storage and naming implementations were reviewed as references; this does not claim to replicate every unrelated CallVault feature.

| Request | Implemented behavior | Verification or limitation |
|---|---|---|
| Offline capture and working VoIP/Wi-Fi route | Detached Embedded ADB helper and communication-playback policy retained. | Earlier S23 voicemail capture is the physical evidence; reconnect the helper after updating. |
| Record all indicator | Requires its explicit action and running tracks with PCM for every non-hidden source. Empty, paused and partial selections stay gray; expanded hidden routes remain excluded. | Pure logic and real microphone capture checks passed. |
| Waveform colors and smooth motion | Gray previews, accent-colored recording, measured peak interpolation per display frame, animated player progress and short button/screen feedback. | Reduced-motion settings respected; no generated live signal. |
| Notifications and readable errors | Capture pause/resume/bookmark/stop, playback actions, pairing reply, saved-file, routing and repair notices, with in-app Alerts history. Policy/initialization/routing errors include explanations and steps. | Notification actions and pairing-discovery fixture verified. Physical TLS pairing remains a phone check. |
| Clean Sessions and full-screen call | Compact cards with inline play and real waveform; tap recording for its dedicated screen with all tracks, seeking, skips, speed, rename and sharing. | Full-screen media playback, waveform seek and notification controls verified. |
| Text, sizing and safe screen edges | Standard 100% text default, consistent sans-serif hierarchy, wrapping supporting text and system-bar/cutout/bottom insets. | S23 cutout and unusual accessibility-scale acceptance remain physical checks. |
| Global formats | Changing the default removes all per-source format overrides, including hidden/future headset presets. M4A, WAV, Opus/WebM and PCM. | Format propagation tests passed; encoder failure retains WAV. |
| Source editing and hidden group | Pencil, drag order, move-up, Hide/Show; hidden routes acquire previews only while expanded and Sources is visible. | Catalog/order/monitor-release checks passed. Other previews pause during capture; recording tracks stay live. |
| Four density views | Detailed, Comfortable, approximately 32dp Compact rows, and two-column Mini. Compact formats/details available on tap. | Approximate 0.5cm depends on physical density; headset warnings need extra room. |
| Empty recording prevention | Empty selection rejected; failed no-PCM sessions and empty WAV tracks removed. Real silent PCM retained for diagnosis. | Failed-session test passed. Audible activity does not establish both call parties. |
| Multiple recommendations | All valid audible sources within 12 dB of strongest and above silence threshold; start tracks or add to an active session. | Multiple/silent/invalid-level tests passed. Suggested tracks may overlap. |
| Automatic calls | User-armed foreground detection, debounce, restart suppression, VoIP + phone mic + carrier candidates and playback prearm. | State-machine tests passed; actual app/OEM behavior needs phone acceptance. |
| Caller/app/direction naming | Optional local call-log/contact lookup and ongoing call-notification identity; customizable filename fields. Missing/ambiguous values omitted. | Filename, call-log and notification fixtures verified; apps can hide caller/direction. Optional access must be granted. |
| Save location and metadata | Persistent document-tree folder picker, private staging, finished-file copy, rename when supported, fallback notice and custom-folder JSON sidecar. Old folder grants retained for saved-file access. | Real local-folder export/indexing verified; SD-card and cloud providers vary. |
| Files and Samsung Recent | Default MediaStore publication with audio metadata; custom local copies request scanning. | Android indexing verified. Samsung Recent and cloud-provider sorting remain physical/provider checks. |
| Phone-only ordinary microphones | Local AudioRecord requests built-in input and verifies actual route before accepting PCM; wrong/unknown routes fail with help. | Built-in input and helper bypass verified on emulator. Protected call/playback channels remain separate policy captures. |
| Explicit Bluetooth microphone sources | Three presets appear for connected call-capable devices. Preview stays off until Start monitoring or Record, with a media-interruption warning. | No-headset/automatic-preview guard verified. Actual CMF start/stop/disconnect needs hardware. |
| Bluetooth settings | Nearby permission, preferred headset/address, Android settings shortcut, phone-preview toggle, explicit call-route preparation, mono sample rate and idle release. External call mode is respected. | CMF/S23 media playback behavior remains a physical check. |
| Logs and debugging tools | Existing probes, sweeps, pipeline tests, WAV repair, routing/mix/MKA, inspection and diagnostic export retained. | Privileged route outcomes depend on device policy. |
| Git and APK | Signed version 0.3.0, same package/key as earlier releases, source versioning and updated publisher. | Delivery message records actual push outcome. |

API references: [AudioRecord routing](https://developer.android.com/reference/android/media/AudioRecord), [communication devices](https://developer.android.com/reference/android/media/AudioManager), [document access](https://developer.android.com/training/data-storage/shared/documents-files), [call notifications](https://developer.android.com/reference/android/app/Notification), [call log](https://developer.android.com/reference/android/provider/CallLog.Calls), and [contact lookup](https://developer.android.com/reference/android/provider/ContactsContract.PhoneLookup).
